# 电梯限速器检测报告生成系统 - 发布包

## 📦 打包文件清单

### 必需文件（核心运行文件）

1. **主程序文件**
   - `table_OCRV41ForCsharp_net_framework_standalone.exe` - 主可执行文件（约11MB，已嵌入所有依赖项）

2. **配置文件**
   - `nlog.config` - 日志配置文件
   - `default.json` - 默认配置文件
   - `key.json` - API密钥配置文件（需要用户自行配置腾讯云OCR密钥）

### 可选文件（文档和说明）

3. **文档文件**
   - `README.md` - 项目说明文档
   - `LOGGING_GUIDE.md` - 日志功能使用指南

## 🎯 最小发布包（仅核心功能）

如果只需要基本功能，最少需要以下文件：
```
发布包/
├── table_OCRV41ForCsharp_net_framework_standalone.exe
├── nlog.config
├── default.json
└── key.json
```

## 📋 系统要求

- **操作系统**: Windows 7 SP1 或更高版本
- **.NET Framework**: 4.7.2 或更高版本
- **网络连接**: 需要访问腾讯云OCR API

## ⚙️ 使用前配置

1. **配置API密钥**：编辑 `key.json` 文件，填入有效的腾讯云OCR API密钥
2. **检查网络**：确保能够访问腾讯云服务
3. **运行程序**：双击 `table_OCRV41ForCsharp_net_framework_standalone.exe` 启动

## 🔧 故障排除

- 如果程序无法启动，请检查是否安装了 .NET Framework 4.7.2
- 如果OCR功能异常，请检查 `key.json` 中的API密钥配置
- 日志文件会自动生成在程序目录的 `logs` 文件夹中
